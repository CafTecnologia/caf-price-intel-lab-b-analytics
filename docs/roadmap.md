# Roadmap por fases

## Fase 1

- Monorepo y contratos estables.
- Core engine mínimo.
- API y frontend iniciales.
- Addon Odoo instalable.

## Fase 2

- OCR local robusto.
- Extracción RAW avanzada.
- Normalización y validaciones ampliadas.
- Bandeja de excepciones con evidencias visuales.

## Fase 3

- Benchmark web.
- Assessment financiero configurable por categoría.
- Reportes Excel/PDF.

## Fase 4

- Hardening.
- Cobertura de tests ampliada.
- Observabilidad.
- Datos demo y documentación extendida.
