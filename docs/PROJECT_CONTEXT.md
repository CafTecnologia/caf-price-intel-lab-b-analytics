# Lab B - Analytics - Project Context

## Proposito
Laboratorio B para analisis de precios. Es el mas trabajado y amplio, pero requiere estabilizacion.

## Relacion con CAF Price Intelligence
Este proyecto hace parte de los laboratorios A/B/C que buscan resolver la misma necesidad: analisis de estudios previos, estudios de mercado, precios techo, fichas tecnicas e items para contratacion estatal.

## Reglas de trabajo
- Evitar refactors grandes sin plan. Separar correcciones de errores de nuevas funciones.
- No conectarse a produccion.
- No guardar claves en el repositorio.
- Mantener cambios en ramas Git.
- Documentar decisiones importantes en docs/DECISIONS.md.
- Mantener tareas abiertas en docs/TODO.md.
